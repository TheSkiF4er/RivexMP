# Roadmap

| Phase | Deliverable | Exit criteria |
| --- | --- | --- |
| 0.1 | Foundation & independently testable mock transport | Working local API, Console, Tauri shell, SDK, UDP sample, CI |
| 0.2 | Persistent control plane | PostgreSQL migrations, service accounts, scoped API tokens, durable discovery, health probes |
| 0.3 | Authenticated game transport | Binary protocol, encryption, replay protection, interest management and benchmark harness |
| 0.4 | Resource runtime | Sandboxed JS/TS runtime, versioned event ABI, manifest validation, CPU and memory quotas |
| 0.5 | Developer platform | CLI, local debugger, resource packaging, migration tools, C# feasibility study |
| 0.6 | Player experience | Signed launcher updates, CDN, VoIP, server moderation, observability |
| 0.7 | Scale & security | Profiling, load tests, anti-abuse controls, security review |
| Later | Game compatibility | Only after legitimate PC integration interfaces and rights are established |

Dates and player capacity are intentionally unspecified; performance claims require measurements.
