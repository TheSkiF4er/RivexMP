# Game compatibility and legal boundary

RivexMP is independent software. Its source licenses apply **only** to RivexMP code and do not grant rights to GTA VI or other third-party games.

- No proprietary game data, leaked binaries, GTA VI native calls or game-specific reverse-engineered code is included.
- In-game integrations must be assessed against the applicable game EULA, technical restrictions, copyright law and any applicable authorization or developer program.
- A system that runs from Russia is not automatically exempt from rights held by Rockstar Games or Take-Two Interactive.
- A working mock Dedicated Server is not evidence of future GTA VI compatibility.

This document records project boundaries, not legal advice. Obtain qualified legal review before advertising or shipping game-specific compatibility.
